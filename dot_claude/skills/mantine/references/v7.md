# Mantine 7.x

Baseline for the shared guidance in `SKILL.md`. Everything there was written against 7.x, so this file is short: it records the 7.x-specific facts that later majors changed, so you don't apply an 8.x/9.x idiom to a 7.x project.

## Facts specific to 7.x

- **Form validation**: `import { zodResolver } from '@mantine/form'` (also `yupResolver`, `superstructResolver`). Later 7.x minors moved these to `mantine-form-zod-resolver` etc.; check which import the repo already uses and match it.
- **Dates are `Date` objects**: every `@mantine/dates` component takes and returns `Date | null` (`[Date | null, Date | null]` for ranges). Timezone handling goes through `DatesProvider`'s `timezone` setting.
- **`DateTimePicker`** takes `timeInputProps` to configure its inner `TimeInput`. There is no `TimePicker` component; use `TimeInput`.
- **`CodeHighlight`** (`@mantine/code-highlight`) depends on `highlight.js` directly; no adapter setup needed.
- **`Popover`/`Tooltip`** accept `positionDependencies` for manual repositioning; dropdowns stay visible when the target scrolls out of view.
- **`Collapse`** uses `in`; **`Spoiler`** uses `initialState`; **`Grid`** uses `gutter` and may need `overflow="hidden"`; `TypographyStylesProvider` is the typography wrapper; `<Text color="...">` still works (prefer `c` anyway — it's forward-compatible).
- **`Menu.Item`** exposes `data-hovered` for styling the hovered item.
- **`useForm<Values, TransformFn>`**: the second generic is the *transform function type*, not the transformed values type.
- **`theme.defaultRadius`** default is `sm`. `Switch` has no thumb indicator by default.
- `@mantine/core/styles.css` is the only global stylesheet; there are no granular `styles/*.css` exports.

## Coming from 6.x

`sx`, `createStyles`, `theme.fn.*`, and Emotion are gone. Styling is CSS Modules + `classNames` + CSS variables (see `SKILL.md` §4). Follow `https://mantine.dev/guides/6x-to-7x/` for the rest.

## Pinning

New projects should not start on 7.x unless something else in the repo (React < 19.2, a 7.x-only extension) forces it — see `v9.md`.
