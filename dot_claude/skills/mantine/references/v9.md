# Mantine 9.x

Differences from the shared guidance in `SKILL.md`, and the breaking changes when moving up from 8.x. Compiled from the official 8.x → 9.x migration guide; **not yet validated on a real upgrade in one of our repos** — when you do the first one, replace this note with what actually broke.

For a full migration, fetch `https://mantine.dev/llms/guides-8x-to-9x.md` rather than working from this summary.

## Prerequisites

- **React 19.2 or later.** This is the decision that matters for new projects: if the repo can't be on React 19.2+, it stays on 8.x.
- `@mantine/tiptap` needs `@tiptap/*` 3.x; `@mantine/charts` needs `recharts` 3.x.

## What changes for code you write

- **Form validation uses Standard Schema.** `zodResolver` is gone from `@mantine/form`. Use the built-in `schemaResolver(schema, { sync: true })` with a Standard-Schema library — zod v4 (`import { z } from 'zod/v4'`), Valibot, ArkType. This is the change most likely to break a copied 7.x/8.x form.
- **`useForm<Values, TransformedValues>`**: the second generic is now the *transformed values type*, not the transform function type. Update any explicit second generic.
- **`Text`/`Anchor` `color` prop removed.** Use the `c` style prop.
- **`light` variant colors are now solid**, not transparent. Pass `cssVariablesResolver={v8CssVariablesResolver}` to `MantineProvider` to keep 8.x colors during migration; drop it once the theme is reviewed.
- **`theme.defaultRadius` default is `md` (8px)**, was `sm` (4px). Set `defaultRadius: 'sm'` explicitly to keep the old look — the shared theme in `SKILL.md` §2 already does.
- **Renames**: `TypographyStylesProvider` → `Typography`; `Collapse in` → `expanded`; `Spoiler initialState` → `defaultExpanded`; `Grid gutter` → `gap` (plus new `rowGap`/`columnGap`); `Grid` uses CSS `gap`, so `overflow="hidden"` is no longer needed.
- **`Popover`/`Tooltip` `positionDependencies` removed** — position recalculates automatically.
- **Hooks**: `useFullscreen` → `useFullscreenElement` / `useFullscreenDocument`; `useMouse` → `useMouse` (ref) / `useMousePosition` (document); `useMutationObserver` third argument → `useMutationObserverTarget`; `useHeadroom` returns `{ pinned, scrollProgress }` instead of a boolean; `useLocalStorage`/`useSessionStorage` (and `read*StorageValue`) type as `T | undefined` when no `defaultValue` is given — provide one.
- **Type renames**: `UseScrollSpyReturnType` → `UseScrollSpyReturnValue`, `StateHistory` → `UseStateHistoryValue`, `OS` → `UseOSReturnValue`. Components and hooks now also export namespace types (`Button.Props` style).
- **`Notifications` `pauseResetOnHover`** now pauses all visible notifications on hover; set `pauseResetOnHover="notification"` for the 8.x behaviour.
- New: `@mantine/schedule` package (calendar scheduling views with drag-and-drop) — a real dependency decision, not a drop-in.

## Carried over from 8.x

String date values, `TimePicker`, `CodeHighlight` adapters, `Popover hideDetached`, `Menu.Sub`, shared `Portal` node — everything in `v8.md` still applies on 9.x.
