# Mantine 8.x

Differences from the shared guidance in `SKILL.md`, and the breaking changes when moving up from 7.x. Compiled from the official 8.0.0 changelog; **not yet validated on a real upgrade in one of our repos** — when you do the first one, replace this note with what actually broke.

For a full migration, fetch `https://mantine.dev/llms/guides-7x-to-8x.md` rather than working from this summary.

## What changes for code you write

- **Dates are strings.** All `@mantine/dates` components take and return `string | null` in `YYYY-MM-DD` or `YYYY-MM-DD HH:mm:ss` format — no `Date` objects, no timezone info. Convert at the edges with `dayjs`/`date-fns` if you need a `Date` or a timezone. `DatesProvider` no longer has a `timezone` option. `DateInput` lost `preserveTime`.
- **`TimePicker`** replaces `TimeInput` for anything beyond the basics (12h/24h, dropdown, seconds). `DateTimePicker` now wraps `TimePicker`; configure it with `timePickerProps`, not `timeInputProps`. New `TimeValue` (display) and `TimeGrid` (slot picker) components.
- **Form validation**: `zodResolver` still exists in 8.x (`mantine-form-zod-resolver` or `@mantine/form` depending on minor); `useForm`'s second generic is still the transform *function* type. `setFieldValue` types are stricter — a wrong-typed value is now a compile error, not a runtime surprise.
- **`CodeHighlight`** no longer bundles `highlight.js`. Wrap the app in `CodeHighlightAdapterProvider` with `createShikiAdapter` (recommended; install `shiki`) or `createHighlightJsAdapter`. Without an adapter, code renders unhighlighted.
- **`Popover` `hideDetached`** is on by default: the dropdown hides when the target is `display: none`, removed, or scrolled out of view. Pass `hideDetached={false}` for the old behaviour.
- **`Menu` supports submenus** (`Menu.Sub`, `Menu.Sub.Target`, `Menu.Sub.Item`, `Menu.Sub.Dropdown`). `Menu.Item` no longer sets `data-hovered` — style with `:hover`/`:focus`.
- **`Portal` `reuseTargetNode`** defaults to `true` — all portals share one node. Usually invisible; matters if you targeted the portal node in CSS or tests.
- **`Switch`** shows a thumb indicator by default; `withThumbIndicator={false}` to remove it.
- **Global styles are split**: `@mantine/core/styles/baseline.css`, `default-css-variables.css`, `global.css`. `@mantine/core/styles.css` still includes all three, so the shared setup in `SKILL.md` is unchanged.
- **Theme size types can be augmented** (`MantineThemeSizesOverride`) for custom `spacing`, `radius`, `breakpoints`, `fontSizes`, `lineHeights`, `shadows` keys — see `theming.md`.
- **`@mantine/carousel`** now requires `embla-carousel` and `embla-carousel-react` installed explicitly; embla props move under `emblaOptions`; `speed`, `draggable`, `useAnimationOffsetEffect`, and the `Embla` type are gone.
- New: `Heatmap` in `@mantine/charts`, `Kbd` `size` prop, `ScrollArea` `content` selector, stricter `wrapperProps` types on inputs.

## Things that did not change

Styling model, provider setup, `@mantine/form` API shape, hooks list, notifications, `AppShell`, `mantine-datatable` usage — the shared guidance applies as written.
